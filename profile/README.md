# Aveno Digital

We build software — for clients, and for ourselves.

**Agency work.** Web and mobile applications, backend systems, and the infrastructure
around them. From first concept to production and the maintenance that follows.

**Our own products.** Apps and services we design, ship, and run end to end.

## How we work

- `main` is always deployable. Changes land through pull requests.
- Every repository documents its own setup in its README — clone, install, run.
- Issues and pull requests follow the templates in this organization.

## Getting in touch

Open an issue in the relevant repository, or reach out through
[avenodigital.com](https://avenodigital.com).
