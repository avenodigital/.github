# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Use GitHub's private vulnerability reporting instead: go to the **Security** tab of the
affected repository and choose **Report a vulnerability**. This creates a private
advisory visible only to us.

Include, as far as you can:

- what the vulnerability allows an attacker to do
- the affected repository, version, or commit
- steps to reproduce it

## What to expect

- We acknowledge reports within **5 business days**.
- We aim to confirm or dismiss the finding within **14 days** of acknowledgement.
- We will tell you when a fix ships, and credit you in the advisory unless you prefer
  otherwise.

## Scope

This policy covers the source code in Aveno Digital repositories. Vulnerabilities in
third-party dependencies should be reported to the upstream project; tell us as well if
one of our repositories is affected.
